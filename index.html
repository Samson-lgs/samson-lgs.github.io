Final Year Project · Machine Learning · Medical Imaging

🧠 Brain Tumor Detection & Classification

My final year project develops an automated brain-MRI classification framework for four categories: Glioma, Meningioma, No Tumor and Pituitary. The workflow resizes MRI images to 160×160 pixels, normalizes pixel intensities and converts them into feature vectors for supervised classification. KNN, MLP, Decision Tree, Random Forest and Extra Trees are trained and compared using accuracy, precision, recall, F1-score, ROC-AUC and confusion-matrix analysis. The evaluated results reported 95.58% test accuracy for Extra Trees and 94.29% for Random Forest.

🌫️ AQI Prediction System

A real-time air-quality monitoring and 48-hour forecasting system for Indian cities. It integrates CPCB, OpenWeather and IQAir data, exposes REST endpoints with Swagger documentation, rate limiting and health checks, and provides a dashboard with maps, rankings, trends, comparisons, alerts and forecasts. The ML layer uses Linear Regression, Random Forest and XGBoost, combines model outputs using a median-of-models approach, applies diurnal adjustments and bounds forecast trajectories. The repository also includes batch-first API handling, frontend caching/retry behavior, PostgreSQL support, automated tests and Render/Docker deployment configuration.
